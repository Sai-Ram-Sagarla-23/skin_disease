      Predictions come from a hybrid ResNet50 + ViT model trained on HAM10000 dermoscopic images, running client-side via ONNX Runtime Web. Photographs from a phone or webcam differ substantially from that distribution, so camera results are a demonstration of the pipeline rather than a meaningful assessment. Nothing in this interface replaces examination by a clinician.

      Model source

      The model runs entirely in this browser tab via ONNX Runtime — no server. It only needs to fetch two static files once.

      These default to the model hosted at huggingface.co/sai2318/best. Change them only if you move the model elsewhere. Without a reachable model file, the page runs in simulated mode, where the maps and probabilities are generated in the browser and are not model output.
